Resume
Next step

- The process should auto-run by default using the existing timing.
- Clicking Pause freezes the process on the currently active stage.
- Nothing should disappear or advance while paused.
- The active stage remains visibly highlighted.
- Completed stages remain visible.
- Clicking Resume continues automatic progression.
- Clicking Next step advances exactly one stage while remaining paused.

Keep these controls subtle and consistent with the existing Deal Signal design system.

Do not make them look like media-player controls.

“Hide process”
“Replay process”

View process:
- restores all completed stages

Replay process:
- resets only the process animation
